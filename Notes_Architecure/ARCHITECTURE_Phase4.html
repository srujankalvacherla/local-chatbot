🔄 RAG Chain Architecture Flow

📥 Input
User Query: "your question"
1
🔍 Query Embedding
Embeds your question using the same embeddings model to convert text into a numerical vector
↓
2
🗂️ Vector Search (Retriever)
ChromaDB searches for the top-k most relevant chunks using cosine similarity between vectors
↓
3
📝 Prompt Construction
Fills {context} with retrieved chunks and {question} with your original question using RAG_PROMPT template
↓
4
🤖 LLM Processing
Sends the complete prompt to ChatOllama (LLM) to generate a contextual answer
↓
5
📤 Return Results
Returns answer along with source documents (the chunks used to generate the response)
📤 Output
{ "result": "answer text", "source_documents": [chunk1, chunk2, ...] }
⚙️ Key Configuration
Chain Type: "stuff" (combines all chunks into single prompt)
Search Type: Cosine similarity
Top-k: Configurable constant (TOP_K)
