🗂️ 2. Vector Database Deep Dive

Inside ChromaDB: The Vector Filing Cabinet

In traditional databases (like SQLite or PostgreSQL), data is stored in rows and columns of strict numbers and text. But in a Vector Database like ChromaDB, there are no traditional tables. Instead, we organize data inside Collections. Your app creates a collection named local_docs. Here is what is actually saved when you click **"Index docs"**:

ID 🔑
Document Chunk 📄 (Text)
Embedding Vector 📐 (Math Coordinates)
Metadata 🏷️ (Filters)

doc_chunk_002

{"source": "docs/rag_guide.pdf", "page": 3}
🔍

Semantic Search

Traditional search looks for exact letters. ChromaDB calculates the similarity between the user's query vector and all stored document vectors, letting the app find relevant concepts even if the user uses completely different vocabulary!

🏷️

Metadata Filtering

Using structured keys (like source or page), Chroma can filter searches instantly—for example, searching only inside a specific PDF or restricting the context to a single document page range.

⚡

Offline Speed

Everything in Chroma is written to ./chroma_db/ on your local disk. It does not require any external cloud account or internet connection, keeping your files completely secure and private.

📊 4. High-Level Sequence Architecture

End-to-End Execution Sequence

How user inquiries flow through Streamlit, retrieve vector data, format prompt templates, and return models tokens.

sequenceDiagram autonumber participant User as User UI (app.py) participant LCEL as LangChain LCEL (rag.py) participant Chroma as Vector DB (Chroma) participant Ollama as Ollama API participant Model as Phi-3 Model User->>LCEL: Enter question string LCEL->>Chroma: similarity_search(question, k=3) Chroma-->>LCEL: Return top-3 text chunks LCEL->>LCEL: Format prompt template ({context} + {question}) LCEL->>Ollama: Send formatted prompt via HTTP Ollama->>Model: Run model token inference Model-->>Ollama: Yield generated token array Ollama-->>LCEL: Stream complete answer LCEL-->>User: Render output answer + source metadata
🛠️ 5. Core Technology Stack
🎨
Streamlit
A Python framework that creates beautiful interactive web UIs instantly without writing HTML, CSS, or JS.
🗄️
ChromaDB
A specialized database that stores text as numerical vectors to allow lightning-fast relevance searches.
⛓️
LangChain
The orchestration layer. Combines LLMs, prompts, and databases into modular "Chains" using modern LCEL syntax.
🧠
LangGraph
Maintains persistent conversational memory (threads) across state variables using memory checkpoints.
🦙
Ollama
Runs state-of-the-art open-source LLMs (like Phi-3 or Gemma) entirely offline on your local computer.
