The Local Chatbot supports PDF, TXT, and Markdown files for RAG indexing.
Each file is split into chunks of 500 characters with 50-character overlap.

## How RAG Works
RAG stands for Retrieval-Augmented Generation. When you ask a question,
the system converts it to a vector, searches ChromaDB for similar chunks,
and passes those chunks to the language model as context. The model then
answers based only on the retrieved content.
